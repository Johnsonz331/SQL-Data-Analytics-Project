# SQL Data Analytics Project

## Project Overview
This project demonstrates the use of **SQL** for in-depth Exploratory Data Analysis (EDA) to extract actionable business insights from raw data. By leveraging complex queries, aggregate functions, and data cleaning techniques, the project focuses on solving specific business problems and optimizing decision-making processes.

## Data Source
The Data Warehouse used in this analysis was built and managed in another project:
* **Data Warehouse Project:** [SQL-Data-Warehouse-Project](https://github.com/Johnsonz331/SQL-Data-Warehouse-Project/tree/main)

## Reference Implementation
This project is a functional replication of the project by **DataWithBaraa**. The goal of this repo is to practice and demonstrate the deployment of these analytical queries within my custom data environment.
